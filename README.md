### How I build

I ship LLM features in production. Estudador generates practice questions with the
DeepSeek API, checks them against the source curriculum, and keeps them in a shared pool,
so 43.5% of exercises are served without a model call. I have also built on the OpenAI and
Anthropic APIs.

Day to day I write code with coding agents — Claude Code, and Gemini in Antigravity — and I
review what they write. My runbooks are agent skills too, so a production deploy follows
the same steps I would.

SININ and the Sistema de Retomada, both written up on the site, were built entirely by
hand, before any of this existed.
